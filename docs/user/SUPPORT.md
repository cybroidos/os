# Getting help

- **Questions and problems:** open an issue on GitHub (not for security
  problems), or write through the contact form at https://cybroid.com.
- **Organisations:** Cybroid installs, manages and supports CybroidOS across
  labs and offices under a service agreement: https://cybroid.com/cybroidos.
- **Security problems:** follow [SECURITY.md](../SECURITY.md).

Please include the CybroidOS version (`cat /etc/os-release`), the computer's
model, what you expected and what happened, and the output of
`journalctl -b -p warning` if it helps.

CybroidOS comes with no warranty, as set out in its licences (`LICENSE`,
`LICENSE-ASSETS`). Debian's packages keep their own licences.
