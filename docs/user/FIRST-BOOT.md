# The first start

After installation CybroidOS starts quietly behind its own splash and opens
the sign-in screen with the account you created.

- **Look:** choose Horizon or Hex, light or dark, in **Settings → Appearance**.
  You can change it at any time.
- **Wi-Fi, sound and displays:** in **Settings**.
- **Updates:** they install by themselves. **Settings → Updates** shows what
  arrived and lets you check now.
- **Your organisation's network:** if your organisation uses Tower, join it
  from **Settings → Network**.
- **Terminal:** zsh, with suggestions from your history as you type (→ or Tab
  takes one) and Ctrl+R to search it.

The firewall is on and refuses incoming connections. Remote desktop and SSH
are off until you turn them on.
