# Support

| Edition | Support |
|---|---|
| Core | Community support via GitHub Issues (non-security only) |
| Education | Through your institution's administrator, then Cybroid Technologies (U) Ltd |
| Developer / Professional | Paid support — contact support@cybroid.com |
| Enterprise / Security | Contractual SLA — contact support@cybroid.com |

## Reporting security issues

**Never open a public issue for a security vulnerability.** Follow
`docs/SECURITY.md` and email security@cybroid.com.

## Information to include

- edition and image version (see `/etc/os-release`);
- target hardware (e.g. Raspberry Pi 4, 4 GB);
- what you expected and what happened;
- relevant output of `journalctl -b -p warning`.
